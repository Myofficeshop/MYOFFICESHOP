# Specs Skill

## Job
Provide the measurable design values that implementation should use.

## Inputs
- Current index.html
- Verified project materials
- Any approved design decisions

## Source of truth
Until a dedicated design system is established, preserve the existing MYOFFICESHOP values already present in index.html rather than inventing replacements.

Known current implementation values:
- Font family: Archivo
- Primary text colour: #12203A
- Secondary text colour: #4A5972
- Page background: #FBFAF7
- Alternate section background: #F2EFE8
- Rule colour: #D8D3C7
- Signal / CTA colour: #BE1622
- Graph colour: #2F5D8C
- Focus colour: #2F5D8C
- Main content width: 1180px
- Base font size: 17px

## Refusal
Never create a new colour, spacing value, font or component state because it 'looks right'.

## Check
Every implemented visual value must either match the current source or be explicitly approved and documented.
