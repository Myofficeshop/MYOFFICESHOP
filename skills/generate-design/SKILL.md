# Generate Design Skill

name: generate-design
use when: a MYOFFICESHOP screen needs to be created or structurally revised

## Inputs
- Read day-one.md
- Read skills/design-principles/SKILL.md
- Read skills/specs/SKILL.md
- Read materials/LICENSES.md

## Steps
1. Restate the screen's single job in one line.
2. Identify the user moment immediately before and after the screen.
3. Use the existing components, colours and typography from the specs.
4. Use real product copy where available; mark missing data as VERIFY rather than guessing.
5. Build the minimum screen needed for the job.
6. Check the screen against the design principles.

## Output
A proposed or implemented screen with the relevant content and a short verification note.

## Refusal
Never invent design values, product data, URLs, claims or interactions.

## Done
The screen is done when the intended user job is clear and every used value traces to a source.
